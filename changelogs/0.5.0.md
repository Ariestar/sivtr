# 0.5.0 - unreleased

## English

### Added

- Reading mode: structure blocks (tool calls, results, skills, thinking) fold to `<:…:>` tags, and clicking a tag expands/collapses its block — merged tool call+result groups fold as one unit, and the clicked block is highlighted like a list row.

### Fixed

- Id-less tool calls and results group only when they share the same tool name; distinct call ids never merge.
- Multi-line tool descriptions normalize to a single tag line.
- Plain text starting with `<:/` is no longer treated as a structure close marker.
- Clicking below the last content line no longer toggles the final block.

## 中文

### 新增

- 阅读模式：结构块（工具调用、结果、skill、thinking）折叠为 `<:…:>` 标签，点击标签可展开/折叠对应块——合并的工具调用+结果组折叠为一个单元，被点击的块以列表行样式高亮。

### 修复

- 无 call id 的工具调用与结果仅在工具名相同时合并；不同的 call id 永不合并。
- 多行工具描述规范化为单行标签。
- 以 `<:/` 开头的普通文本不再被当作结构结束标记。
- 点击最后一行内容以下的空白不再触发最后一个块的折叠。

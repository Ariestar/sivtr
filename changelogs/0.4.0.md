# 0.4.0 - 2026-08-04

## English

### Breaking

- Part refs now use `p<n>` instead of `<i|o>/<n>`: `codex/abc123/2/o/1` is now `codex/abc123/2/p1`. Line refs (`.../3/12`) are gone — `WorkAt` is `Whole | Part(seq)`. ([a9f3840](https://github.com/Ariestar/sivtr/commit/a9f3840), [f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3), [0552981](https://github.com/Ariestar/sivtr/commit/0552981))
- `--kind` values renamed: `user_message` → `user`, `assistant_message` → `assistant`, `tool_output` → `tool_result`, `text` removed. ([a9f3840](https://github.com/Ariestar/sivtr/commit/a9f3840), [f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3))
- `filter` and `work parts` no longer take `--io`; use `--kind` (e.g. `--kind tool_result`) or `-m` to narrow parts. ([f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3))
- Search is BM25-primary: a positional `QUERY` (or `--match`) makes `relevance` the default sort over the whole source. `--match` alone keeps the regex-filter behavior and doubles as the rank query. ([4e06d59](https://github.com/Ariestar/sivtr/commit/4e06d59), [a257b0b](https://github.com/Ariestar/sivtr/commit/a257b0b))
- Default content search now covers tool results and thinking; only tool-call payloads and skill text are excluded as noise (reachable with `--kind` / `-i all`). ([29dcb98](https://github.com/Ariestar/sivtr/commit/29dcb98))

### Added

- BM25-primary search with a positional plain-text `QUERY`, standard BM25 (k1/b) with tf saturation and length normalization, and relevance ranking of the whole source. ([8975cef](https://github.com/Ariestar/sivtr/commit/8975cef), [a257b0b](https://github.com/Ariestar/sivtr/commit/a257b0b))
- Passage retrieval over typed WorkParts (index unit = each typed part, per-kind length normalization, record score = best part) with fielded BM25+ scoring and query-difficulty-gated PRF expansion; CJK bigram tokenization makes Chinese searchable. ([26b828a](https://github.com/Ariestar/sivtr/commit/26b828a), [af1d613](https://github.com/Ariestar/sivtr/commit/af1d613), [f5a0536](https://github.com/Ariestar/sivtr/commit/f5a0536))
- `sivtr eval` benchmarks retrieval quality (recall@k / precision@k / MRR / NDCG@k) against frozen golden-query snapshots; see `docs/retrieval-eval.md`. ([f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3))
- Qoder CLI provider. ([9dacd45](https://github.com/Ariestar/sivtr/commit/9dacd45))
- MCP server exits when idle via `sivtr mcp serve --idle-exit <secs>`, defaulting to the unified `[mcp] idle_exit_secs` config key. ([6eb513b](https://github.com/Ariestar/sivtr/commit/6eb513b), [b44f6f8](https://github.com/Ariestar/sivtr/commit/b44f6f8))
- TUI workspace content search ranks with the shared BM25 engine. ([a2c7604](https://github.com/Ariestar/sivtr/commit/a2c7604))

### Fixed

- Capture recovers output for commands scrolled out of view. ([0b2cf23](https://github.com/Ariestar/sivtr/commit/0b2cf23))
- CLI help text and ref errors repaired: `show` example no longer cites the removed line-ref form, selector errors document `[/p<part>]`, and corrupted `→` arrows in `copy` help are restored. ([0552981](https://github.com/Ariestar/sivtr/commit/0552981))

### Performance

- Agent session files parse in parallel, cached as MessagePack, with stamp-validated session listing caches; search anchors resolve through an O(1) record index; the TUI caches the search corpus across keystrokes. ([9ad5681](https://github.com/Ariestar/sivtr/commit/9ad5681), [575cc3f](https://github.com/Ariestar/sivtr/commit/575cc3f), [c59f80f](https://github.com/Ariestar/sivtr/commit/c59f80f), [15bfcd7](https://github.com/Ariestar/sivtr/commit/15bfcd7), [fec8de2](https://github.com/Ariestar/sivtr/commit/fec8de2))

### Tooling

- CI hardened: `cargo-audit` and Dependabot (cargo / npm / actions), docs-site `astro check` + build, VS Code extension tests, an MSRV job that compiles the workspace on the declared `rust-version`, per-OS binary smoke tests, and installer smoke tests against the published release. Installers now verify the downloaded archive against the release `SHA256SUMS`. ([c8b50db](https://github.com/Ariestar/sivtr/commit/c8b50db))
- Dropped the deprecated `atty` crate; the declared MSRV is corrected to 1.95 (1.91 was never buildable — `libsqlite3-sys` needs 1.95). ([0612323](https://github.com/Ariestar/sivtr/commit/0612323))
- CI locks dependencies and cancels superseded runs. ([47af25d](https://github.com/Ariestar/sivtr/commit/47af25d))

### Documentation

- BM25-primary search syntax documented; docs and the bundled `sivtr-memory` skill aligned with the current search/ref surface (positional QUERY, `p<n>` part refs, current `--kind` values). ([48dbb57](https://github.com/Ariestar/sivtr/commit/48dbb57), [453d1d2](https://github.com/Ariestar/sivtr/commit/453d1d2))
- Design docs (`docs/uri.md`, `docs/retrieval-eval.md`, `docs/retrieval-literature.md`) are now tracked in the repository. ([adc9ef1](https://github.com/Ariestar/sivtr/commit/adc9ef1))

## 中文

### 破坏性变更

- part ref 从 `<i|o>/<n>` 改为 `p<n>`：`codex/abc123/2/o/1` 现在是 `codex/abc123/2/p1`。行 ref（`.../3/12`）已移除——`WorkAt` 只有 `Whole | Part(seq)`。([a9f3840](https://github.com/Ariestar/sivtr/commit/a9f3840), [f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3), [0552981](https://github.com/Ariestar/sivtr/commit/0552981))
- `--kind` 值改名：`user_message` → `user`、`assistant_message` → `assistant`、`tool_output` → `tool_result`、移除 `text`。([a9f3840](https://github.com/Ariestar/sivtr/commit/a9f3840), [f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3))
- `filter` 与 `work parts` 不再接受 `--io`；改用 `--kind`（如 `--kind tool_result`）或 `-m` 收窄 part。([f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3))
- search 以 BM25 为主：位置参数 `QUERY`（或 `--match`）会把默认排序变为 `relevance`，对整个 source 排序。只用 `--match` 保留正则过滤行为，其文本同时充当排序查询。([4e06d59](https://github.com/Ariestar/sivtr/commit/4e06d59), [a257b0b](https://github.com/Ariestar/sivtr/commit/a257b0b))
- 默认内容搜索现在覆盖 tool results 和 thinking；仅 tool-call 载荷与 skill 文本默认排除（可用 `--kind` / `-i all` 纳入）。([29dcb98](https://github.com/Ariestar/sivtr/commit/29dcb98))

### 新增

- BM25-primary 搜索：位置参数 plain-text `QUERY`、标准 BM25（k1/b，tf 饱和 + 长度归一）、整个 source 按相关性排序。([8975cef](https://github.com/Ariestar/sivtr/commit/8975cef), [a257b0b](https://github.com/Ariestar/sivtr/commit/a257b0b))
- 类型化 WorkPart 段落检索（索引单位 = 每个类型化 part，按 kind 分别长度归一，记录分 = 最佳 part），字段加权 BM25+ 与按查询难度门控的 PRF 扩展；CJK bigram 分词让中文可检索。([26b828a](https://github.com/Ariestar/sivtr/commit/26b828a), [af1d613](https://github.com/Ariestar/sivtr/commit/af1d613), [f5a0536](https://github.com/Ariestar/sivtr/commit/f5a0536))
- `sivtr eval` 用冻结的 golden-query 快照基准测试检索质量（recall@k / precision@k / MRR / NDCG@k）；见 `docs/retrieval-eval.md`。([f3473d3](https://github.com/Ariestar/sivtr/commit/f3473d3))
- Qoder CLI provider。([9dacd45](https://github.com/Ariestar/sivtr/commit/9dacd45))
- MCP server 空闲退出：`sivtr mcp serve --idle-exit <secs>`，默认走统一配置键 `[mcp] idle_exit_secs`。([6eb513b](https://github.com/Ariestar/sivtr/commit/6eb513b), [b44f6f8](https://github.com/Ariestar/sivtr/commit/b44f6f8))
- TUI workspace 内容搜索复用共享 BM25 引擎。([a2c7604](https://github.com/Ariestar/sivtr/commit/a2c7604))

### 修复
